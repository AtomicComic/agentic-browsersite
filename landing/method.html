Benchmarks / Proposed protocol

Dinner across tabs.

Give the agent a fixed review, menus, and two sample booking calendars. Request dinner for two around seven, with an $100 pre-tax budget. Define the accepted time window as 6:30–7:30 PM before each run.

Pass conditions

Match the recommended dish to the dinner menu, calculate a meal for both diners, verify the party size and time, and reach confirmation on the simulated booking site. A run passes only when all four checks succeed.

Reporting

Publish the fixture version, model, extension revision, attempt count, pass rate, median duration and failure reasons. Count timeouts as failures. The homepage replay is illustrative and contributes zero scored runs.
